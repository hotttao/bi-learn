# 销售分析语义索引

状态：已审核的本地合成实验，不是公司正式定义。读取相关主题及其依赖即可，不读取全量模型。当前数据发布与查询模型绑定见 `release.json`，由启动器和查询服务预检。

| 用户要分析什么 | 主题入口 | 所需知识 |
| --- | --- | --- |
| 净收入/净销售额总额、业务日期趋势 | [净收入基础指标](metrics/net-revenue.md) | 订单粒度、退款聚合、日期边界 |
| 按客户当前行业 | [当前行业关系](relationships/current-industry.md) | 基础指标＋客户联合键，当前归属 |
| 按下单时客户行业 | [历史行业关系](relationships/historical-industry.md) | 基础指标＋客户联合键与有效期 |
| 按客户标签 | [可重叠标签关系](relationships/overlapping-tags.md) | 基础指标＋标签成员，组间不可加 |

仅说“行业”时澄清当前还是下单时；仅说“收入”时澄清是否净收入。财务确认收入、毛利及其他未登记维度没有已审核定义，不默认为净收入总额。
