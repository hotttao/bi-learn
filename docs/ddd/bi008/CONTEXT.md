# 008 销售分析上下文

定义本地合成销售分析的统一业务语言，作为实验模型和问题集的术语依据；不代表公司真实业务已经审核。

## 业务术语词典

**Net Revenue（净收入）**：订单实付减累计已记录退款的销售分析金额，退款归属原订单业务日；受控同义词为净销售额。
_禁用替代词_：财务确认收入、毛利。

**Current Customer Industry（客户当前行业）**：客户目前的行业归属，用它分组时历史订单随当前归属变化。
_禁用替代词_：下单时行业。

**Order-time Customer Industry（下单时客户行业）**：订单业务日处于客户行业有效区间时对应的行业，区间起日包含、止日不包含。
_禁用替代词_：客户当前行业。

**Customer Identity（客户身份）**：本实验中由部门和部门内客户编号共同确定的客户。
_禁用替代词_：仅客户编号、仅客户名称。

**Overlapping Customer Tag Group（可重叠客户标签组）**：同一客户可以同时属于多个标签组，其净收入可在不同组中重复出现。
_禁用替代词_：可相加的行业分类。

**Order Grain（订单粒度）**：每行代表一笔订单的分析结果粒度。
_禁用替代词_：订单明细行粒度、退款明细粒度。
